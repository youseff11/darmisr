# دار مصر للنشر — متجر إلكتروني احترافي

مشروع Django متكامل لدار نشر متخصصة في بيع الكتب بصيغتيها الورقية والإلكترونية.

## البنية

- **تطبيق واحد**: `store` — يحتوي على كل منطق المتجر والمحتوى
- **قالب واحد**: مجلد `templates` مركزي بقوالب HTML عربية متجاوبة
- **قاعدة بيانات**: SQLite للتطوير المحلي

## المتطلبات

```bash
pip install Django==6.0.7 Pillow==11.3.0
```

## التشغيل

```bash
cd DarMisr
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

ثم افتح: `http://127.0.0.1:8000`

لوحة الإدارة: `http://127.0.0.1:8000/admin`

## الملفات الرئيسية

- `store/models.py` — نماذج البيانات
- `store/views.py` — منطق العروض
- `store/urls.py` — المسارات
- `store/forms.py` — نماذج الإدخال
- `store/admin.py` — لوحة الإدارة
- `templates/` — قوالب HTML
- `static/` — CSS و JavaScript والصور
